## para clonar o repositório use:

```bash
git clone https://github.com/fritzkliewer/programacao.git
```
Mude para o diretório criado
```bash
cd programacao
```

## para compilar e executar o arquivo .c use:

WINDOWS

instale [MSYS2](https://www.msys2.org/)

compilar:
```bash
gcc progex1-5-11-2026.c -o progex1-5-11-2026.exe
```
executar no command prompt:
```bash
progex1-5-11-2026
```
ou executar no power shell:
```bash
./progex1-5-11-2026
```
LINUX

compilar:
```bash
gcc progex1-5-11-2026.c -o progex1-5-11-2026 -lm
```
executar:
```bash
./progex1-5-11-2026
```
