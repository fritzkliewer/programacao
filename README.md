# programação

atividades e avaliações

## para clonar o repositório use:

```bash
git clone https://github.com/fritzkliewer/programacao.git
```
Mude para o diretório criado
```bash
cd programacao
```

## para compilar e executar os arquivos .c use:

WINDOWS

instale [MSYS2](https://www.msys2.org/)

compilar:
```bash
gcc [nome do arquivo].c -o [nome do arquivo].exe
```
executar no command prompt:
```bash
[nome do arquivo]
```
ou executar no power shell:
```bash
./[nome do arquivo]
```
LINUX

compilar:
```bash
gcc [nome do arquivo].c -o [nome do arquivo] -lm
```
executar:
```bash
./progex1-5-11-2026
```
## para rodar/interpretar os arquivos .py use:
```bash
python3 [nome do arquivo].py
```
