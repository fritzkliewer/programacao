# programacao

atividades e avaliações

## para clonar o repositório use:

```bash
git clone https://github.com/fritzkliewer/programacao.git
```
Mude para o diretório criado
```bash
cd programacao
```

## para compilar e executar o arquivo .c use:

WINDOWS

compilar:
```bash
gcc progex1-5-11-2026.c -o progex1-5-11-2026.exe
```
executar:
```bash
progex1-5-11-2026.exe
```
ou
```bash
progex1-5-11-2026
```
LINUX

compilar:
```bash
gcc progex1-5-11-2026.c -o progex1-5-11-2026 -lm
```
executar:
```bash
./progex1-5-11-2026
```
## para rodar/interpretar o arquivo .py use:

```bash
python3 progex1-5-11-2026.py
```
