## para compilar e executar o arquivo .c use:

WINDOWS

compilar:
```bash
gcc escola3o.c -o escola3o.exe
```
executar:
```bash
escola3o.exe
```
ou
```bash
escola3o
```
LINUX

compilar:
```bash
gcc escola3o.c -o escola3o
```
executar:
```bash
./escola3o
```
## para rodar/interpretar o arquivo .py use:

```bash
python escola3o.py
```
